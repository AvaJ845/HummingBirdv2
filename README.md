# SipNear

Polished, Vivino-inspired wine discovery — **no account**, **one easy button**, wineries around you.

## Native iOS app (Xcode)

Open this in Xcode when you’re ready to test:

```text
SipNearApp/SipNear.xcodeproj
```

See [`SipNearApp/README.md`](./SipNearApp/README.md) for setup, signing, and feature notes.

### Quick start on Mac

1. Open `SipNearApp/SipNear.xcodeproj`
2. Choose an iPhone simulator
3. Select your Signing Team
4. Press **Run** (⌘R)
5. Tap **Find Wineries Near Me**

## Expo / React Native prototype (optional)

An earlier cross-platform prototype lives in [`SipNear/`](./SipNear) if you want a web/Expo Go preview. The **SwiftUI app in `SipNearApp/`** is the primary iOS deliverable for Xcode.
