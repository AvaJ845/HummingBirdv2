# SipNear

Native **SwiftUI** iPhone app — polished wine discovery with **no account** and one easy button to pull wineries around you.

## Open in Xcode (primary)

```text
SipNearApp/SipNear.xcodeproj
```

Full docs: [`SipNearApp/README.md`](./SipNearApp/README.md)

### On your iMac

1. Open the Xcode project  
2. Pick an iPhone simulator (iOS 17+)  
3. Set Signing Team  
4. Run (⌘R)  
5. Tap **Find Wineries Near Me**

When you’re back, we can iterate against the native Simulator together.
